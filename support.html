Alfolio Support

Alfolio organizes bookmarks, feeds, and local documents on your Mac.

Getting started

  • Import a browser bookmark HTML file or drop a link into a collection.
  • Choose a document folder using the Documents toolbar. You can change this folder later.
  • Use the library backup controls to save a copy before resetting the library or moving to another Mac.

When reporting a problem

Include your macOS version, Alfolio version, the steps that reproduce the issue, and any error message. Remove private URLs, documents, or other personal information from screenshots and attachments.
